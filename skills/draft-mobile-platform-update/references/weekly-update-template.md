# Weekly Update Template

Use this template as the final shape. Omit empty sub-bullets, but keep every required top-level section.

```markdown
# Mobile Platform Weekly Update - <Month D-D, YYYY>

Reporting window: <YYYY-MM-DD> to <YYYY-MM-DD>

## Summary

- <1-3 bullets on the biggest movement, risk, or decision this week.>

## Ongoing Projects

### <Project or initiative name>

Wins:
- <Concrete progress from merged PRs or Slack decisions.>

Next Steps:
- <Immediate follow-up, owner if known, blocker/dependency if relevant.>

Estimated Ship Timing:
- <Explicit date/window, "TBD", or carefully labeled inference.>

Sources:
- <PR/slack links, compactly listed.>

## Mobile Platform Roadmap Updates

- <New, changed, delayed, de-scoped, or re-prioritized roadmap item.>
- No material roadmap updates found this week.

## Bigger Project Timelines

- <Project>: <date/window/constraint> - <why it matters and source/confidence.>
- No explicit bigger-project timeline changes found this week.

## Needs Confirmation

- <Question or assumption that would affect accuracy, commitment, or audience expectations.>
```

## Source Collection Checklist

GitHub:
- Merged PRs in the reporting window.
- Platform relevance filter applied.
- Ambiguous PRs inspected by files, body, labels, or linked issue.
- Commit/PR wording translated into user/business impact when possible.

Slack:
- #engineering-frontend searched for engineering status, blockers, and decisions.
- #app-status searched for incidents, releases, regressions, and customer-facing app health.
- Explicit dates, release windows, and commitments captured verbatim enough to preserve meaning.

## Tone Rules

- Write like the Mobile Platform owner briefing stakeholders.
- Favor "we shipped/unblocked/validated" when the source supports it.
- Avoid over-promising. Use "targeting", "estimated", or "needs confirmation" for uncertain timing.
- Keep internal implementation detail only when it explains impact, risk, or timeline.
- Do not list every merged PR unless the user asks for an appendix.
